          Connect your own model (OpenAI-compatible endpoint)
          
      
            
            
            
          
      
          
      
            
            
            
          
      
          
      Local Ollama or LM Studio work from a locally served copy (npm start, then http://127.0.0.1:4173); on an HTTPS page the endpoint must be https:// too. Alternatives: the Desktop Companion (button above) carries the model seat for the whole session, a same-origin model host (npm run start:model) keeps the key server-side, and a WebMCP-capable browser agent can answer turns through cowork_read_turn / cowork_reply_turn.
